# Event flyer

Drop the official event flyer here as **`flyer.jpg`** (or `flyer.png`, then update
the `src` in `index.html`). It appears prominently at the top of the page.

- Recommended: portrait orientation, roughly **1000 × 1500 px**, under ~500 KB.
- If no `flyer.jpg` is present, the page automatically shows a styled,
  CSS-rendered stand-in flyer so nothing looks broken.
